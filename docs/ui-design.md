# MultiProvider LLM Toolbox 交互设计

## 1. 页面结构

单页网页版由顶部栏、Provider/模型配置栏、会话栏、消息区和输入区组成。页面不提供 API Key 输入框，不显示 API Key，不提供 baseUrl 编辑框；Provider 地址和密钥完全由服务端配置。

## 2. MVP 会话与本地数据

- 支持当前会话和最多 5 个本地会话。
- 支持多轮上下文；当前会话最多保留 50 条消息。
- 会话消息、标题和用户自定义提示词保存到 LocalStorage/IndexedDB。
- 刷新页面后恢复本地会话；清除浏览器数据会删除这些内容。
- 不保存 API Key、Authorization、ACCESS_CODE 或服务端地址。

## 3. 页面状态

| 状态 | 页面表现 | 允许操作 |
|---|---|---|
| 初始 | 显示可用 Provider/模型和空消息区 | 选择配置、输入消息 |
| Provider 未配置 | 对应 Provider 标记不可用 | 切换到已配置 Provider |
| 发送中 | 发送按钮禁用，显示停止按钮 | 停止请求 |
| 流式输出 | 助手消息逐段追加 | 停止请求 |
| 成功完成 | 显示完整回答和完成状态 | 继续输入、复制文本 |
| 参数/上游错误 | 显示安全的统一错误和 requestId | 修改后重试或切换 Provider |
| 超时/主动停止 | 保留已收到文本并标记状态 | 继续输入或重试 |

## 4. 交互与安全规则

- 支持基本 Markdown 展示，但不执行未经信任的 HTML/脚本。
- 发送期间不允许切换 Provider/模型；请求结束或停止后恢复。
- 点击停止时取消当前请求；服务端取消上游请求，不伪装成成功完成。
- 模板选择只把模板内容填入输入框；内置模板来自 GET /api/prompts，自定义模板只在浏览器本地管理。
- Provider、模型、发送、停止和错误区域具有可读标签和键盘操作。
- 默认同源加载；跨域只有在服务端显式允许时才可用。
