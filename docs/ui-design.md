# MultiProvider LLM Toolbox 最终交互设计

## 1. 设计目标

最终页面采用安静、紧凑的工作台布局，使用深色中性色、青蓝主色和绿色状态色，不出现特定运营商品牌文字。桌面端优先保证主要工作区适配视口；移动端改为纵向滚动，输入区保持可操作。

页面产品名显示为 `ModelHub`，副标题为“智能对话工作台”。

## 2. 页面结构

```text
顶部栏：产品名 | MOCK/LIVE | Provider 配置状态
主工作区：
  左侧栏：本地会话、导出、提示词库、本地数据说明
  右侧：当前会话标题、当前模型、通知、消息列表
  底部输入区：文档、文本、Provider、模型、高级参数、发送/停止
```

- 桌面宽度大于 720px 时，页面使用固定视口高度，消息列表和侧栏内部滚动。
- 720px 以下时侧栏置于聊天区上方，页面允许滚动，输入区使用 sticky 定位。
- 1000px 以下隐藏顶部 Provider 详细状态；480px 以下输入区控件分行排列。

## 3. 核心交互

### 聊天

- Enter 发送，Shift + Enter 换行，中文输入法组合过程中不触发发送。
- 发送时创建 Assistant 占位并逐段追加 SSE 文本。
- 生成期间显示“停止生成”；停止或失败后保留可重试请求。
- Assistant 消息使用安全 Markdown；有内容时显示复制按钮。
- 当前会话可导出 Markdown。

### Provider 和参数

- Provider 与模型选择位于输入栏右侧，Provider 变化时自动选择其第一个模型。
- 高级设置折叠展示 temperature 和 max_tokens。
- Mock/Live 状态固定在顶部；Live 模式下未配置的 Provider 禁止发送并显示提示。
- 页面不出现 API Key 和 `baseUrl` 输入控件。

### 本地文档

- “本地文档”按钮选择 TXT、Markdown、JSON，可多选。
- 最多 3 个、单个最大 100 KB；待发送文件以标签显示并可移除。
- 发送后清空文档正文；消息气泡仅显示附件名称。

### 会话和提示词

- 最多 5 个会话，支持新建、切换和删除；当前会话可导出。
- 内置提示词按只读分组显示，本地提示词支持保存、选择、插入和删除。
- 选择提示词只填入输入框，不自动发送。

## 4. 状态设计

| 状态 | 页面表现 | 可执行操作 |
|---|---|---|
| 初始加载 | 显示模型/提示词加载状态 | 等待或刷新 |
| 空会话 | 展示核心能力标签 | 选择提示词、文档或输入问题 |
| Provider 未配置 | 顶部状态点和警告提示 | 切换到已配置 Provider |
| 参数非法 | 显示参数范围错误 | 修改参数 |
| 流式生成 | Assistant 增量内容、停止按钮 | 停止生成 |
| 生成完成 | 完整消息和复制入口 | 继续提问或导出 |
| 失败/超时 | 安全错误提示和重试按钮 | 重试或切换配置 |
| 主动停止 | 保留已显示内容并允许重试 | 重试或继续输入 |

## 5. 数据与安全提示

- 会话和自定义提示词保存在当前浏览器 localStorage。
- 文档正文发送前只在页面内存，发送后移除；Live 模式请求会进入所选 Provider。
- Markdown 不执行原始 HTML、脚本或事件属性。
- 配置状态只显示布尔结果，不显示环境变量名、密钥或地址。
- 清理站点数据会删除本地会话和提示词；它们不具备云端备份能力。
